Everything Wisper Note does, and what it doesn’t.

Twelve capabilities. None have shipped yet; all twelve are in development. Each one says which platforms it is built for and what it will not do — because the limitation is usually the thing you actually needed to know.

01

Hold a key, anywhere In development

Hold one key in any application, speak, let go. The text lands at your cursor.

It is not in the build yet. There is no date for it, and there is nothing here to sign up to.

The key is global. It works in the app you were already in — a mail client, an editor, a chat window, a form in a browser tab — because Wisper Note types into whichever window has focus rather than asking you to dictate somewhere else and paste the result back.

There are two ways to run it: hold the key down while you speak and let go when you are finished, or press once to start and once to stop when you have a long thing to say. You choose which key it is, and if something on your machine already owns the one you picked, there is a page in the docs for that.

What it will not do

On iPhone and Android there is no global key — dictation lives in the Wisper Note keyboard, which you switch to.

Built for: macOS and Windows.

02

Cleanup In development

Fillers, false starts, punctuation, paragraph breaks, numbers and dates are handled before the text lands.

It is not in the build yet. There is no date for it, and there is nothing here to sign up to.

Speech has repairs in it. You start a sentence, change your mind, say “um”, run three thoughts together without a full stop. None of that is something you meant to write down, and cleanup takes it out before the sentence reaches you rather than leaving you to hunt for it afterwards.

It runs on the finished transcript rather than on the audio, and it runs before anything reaches your cursor, so what lands is already the version you would have typed. The one failure we test hardest for is the opposite of a missing word — a word that was never said. How that is measured is written out on the how-it-works page.

What it will not do

It edits what you said. If you say something twice on purpose, say it twice on purpose — it removes repeats it reads as stumbles, and it will occasionally read one wrong.

Built for: macOS and Windows.

03

Tone, per app In development

Five levels from very casual to formal, set once per application and applied automatically.

It is not in the build yet. There is no date for it, and there is nothing here to sign up to.

A line to a colleague and a paragraph in a report are not the same register, and dictating both in one voice is why so much dictated text has to be rewritten. At level one the same sentence keeps its contractions and its lowercase start; at level five it is written out in full.

On the desktop the level is attached to the application: choose it once for the place you chat and once for the place you write, and Wisper Note applies whichever matches the window that has focus. There is nothing to set before you speak and no per-message switch to remember.

What it will not do

On iPhone, tone is whatever you choose in Settings. A keyboard extension cannot see which app it is typing into, so per-app rules do not apply there.

Built for: macOS and Windows.

04

Your dictionary In development

Names, jargon and product terms spelled the way you spell them, sent to the transcriber as hints.

It is not in the build yet. There is no date for it, and there is nothing here to sign up to.

Every job has words a general transcriber gets wrong: colleagues’ names, a product with an odd capitalisation, an acronym that means something only inside your company. Add each one once, with the spelling you want, and stop correcting it by hand.

The terms are used twice. They go to the transcriber as hints while you are still speaking, which is what makes the transcript come back right instead of being repaired afterwards, and they are applied again as corrections on the finished text, which catches the ones the hint did not reach.

What it will not do

Terms are sent to the transcriber as hints, and there is a limit on how many fit. Above the limit they are still applied as corrections after the fact.

Built for: macOS and Windows.

05

Snippets In development

Say a phrase you chose, and a longer block of text is inserted in its place.

It is not in the build yet. There is no date for it, and there is nothing here to sign up to.

It is a text expander with no trigger to type. A postal address, a standard reply, a sign-off, a fragment of code you write twenty times a week — give each one a phrase, and say the phrase.

A snippet can carry a variable, so today’s date fills itself in. Snippets expand during cleanup rather than afterwards, which means the sentence around one is punctuated with it in place instead of pasted next to it.

What it will not do

A snippet fires on the phrase you assigned it. If you say that phrase for real, it will expand — pick a phrase you would not otherwise say.

Built for: macOS and Windows.

06

Command mode In development

Select text, hold the key, and say what to do with it: make this shorter, translate this, fix the tense.

It is not in the build yet. There is no date for it, and there is nothing here to sign up to.

The instruction is spoken and the selection is what changes: make this shorter, translate this into Spanish, fix the tense, turn this into bullet points. Nothing is added beside your text — the words you highlighted are the words that are replaced.

It is the same gesture as dictation, pointed at words instead of at silence, so there is nothing new to learn. The selection and your spoken instruction take the same route the cleanup step takes — to our servers, and back.

What it will not do

macOS and Windows only in this version. It reads the text you have selected, which means it needs the same permission that lets it type.

Built for: macOS and Windows.

07

Whisper mode In development

Capture at low volume with gain normalisation, for when you cannot speak at a normal level.

It is not in the build yet. There is no date for it, and there is nothing here to sign up to.

A shared office, a sleeping house, a quiet carriage. Wisper Note lifts a voice barely above a breath to a level the transcriber can read, so you are not choosing between dictating and being overheard.

It is a mode you turn on rather than something that happens on its own, because raising the gain is the wrong thing to do the rest of the time — it lifts the room along with your voice.

What it will not do

It raises the gain, which raises the room as well. It is for a quiet voice, not a loud room.

Built for: macOS and Windows.

08

History In development

A searchable list of what you dictated, with copy and re-insert on every entry.

It is not in the build yet. There is no date for it, and there is nothing here to sign up to.

This is what people ask for in the second week, usually because a good paragraph landed in the wrong window. Find what you said, take the finished text back, and put it where it should have gone without saying it again.

None of it is a second copy of your audio; the audio was never kept in the first place. Entries are yours to delete, and how long they are held is governed by the switch below and by your plan.

What it will not do

Off in privacy mode, by design — nothing is written, so nothing is there to search.

Built for: macOS and Windows.

09

Privacy mode In development

One switch that stops every kind of saving: no history, no learned terms, no usage events, no audio kept.

It is not in the build yet. There is no date for it, and there is nothing here to sign up to.

It is one setting rather than five, because a privacy control you have to assemble out of five checkboxes is one people get wrong. Turn it on and there is nothing to audit afterwards, because nothing was written.

What it cannot change is where your audio goes while you are speaking. That is stated in full below rather than left for you to find out, because a switch that quietly means something narrower than it sounds is worse than no switch at all.

What it will not do

It stops us saving anything. It does not stop the audio leaving your device: transcription still runs on our servers. Turning off the network turns off the product.

Built for: macOS and Windows.

10

Sync In development

Your dictionary, snippets, style rules and history on every device you sign in on.

It is not in the build yet. There is no date for it, and there is nothing here to sign up to.

Teach it a name on the laptop and the desktop knows it too: one dictionary, one set of snippets, one set of per-app tone levels, wherever you signed in.

Sync is off until you turn it on, and it needs an account, because syncing means keeping your data with us, on our servers — described on the privacy page — instead of on your own disk. Leave it off and nothing but the transcription itself leaves the machine you are sitting at.

What it will not do

Requires an account and is off by default. Last write wins; there is no merge UI.

Built for: macOS and Windows.

11

The Wisper Note keyboard In development

A full keyboard for iPhone and Android with dictation on the mic key.

It is not in the build yet. There is no date for it, and there is nothing here to sign up to.

There is no global key on a phone. One app cannot listen for a hotkey while another app is in front, so dictation lives in a keyboard you switch to the way you switch to any other keyboard, and the hold-to-speak gesture sits on the mic key.

It is a complete QWERTY layout rather than a microphone button on its own, because App Review requires a custom keyboard to work as a keyboard (ADR-0004). Cleanup, your dictionary and your snippets apply the same way they do on the desktop; what a keyboard extension cannot see is which app it is typing into, which is why the per-app tone rules do not follow it there.

What it will not do

On iPhone and Android there is no global key — dictation lives in the Wisper Note keyboard, which you switch to.

Built for: iPhone and iPad and Android.

12

In the browser In development

A Chrome extension that dictates into any text field, including contenteditable and Google Docs.

It is not in the build yet. There is no date for it, and there is nothing here to sign up to.

The browser is where most writing happens, and a text field in a page is the hardest place for a desktop app to type into: an editor that intercepts keystrokes will intercept ours. The extension works from inside the page instead, so the text is inserted where the caret already is.

Plain inputs, rich contenteditable areas and Google Docs each need their own insertion path, and it works in Chrome and Edge. Not every site allows it — some editors block an extension from writing into them, which is the limitation below rather than a defect to be fixed later.

What it will not do

Chrome and Edge only. Some sites block extensions from writing into their editors.

Built for: Chrome.

Where it runs

Every platform, and exactly what state each one is in today.

This list is generated from the same file the download page reads. A row cannot say a platform is ready before there is a signed file with a published checksum to hand you — the type will not allow it — so what you see here is the state of the build rather than the state of the plan.

14

Offline

Wisper Note needs a connection to transcribe.

Transcription and cleanup both run on our servers. With no connection there is nothing to hold the microphone open for, so Wisper Note does not open it.

Nothing is queued while you are offline and nothing is captured for later. The pill tells you it cannot reach the network rather than recording something it has no way to finish, which is the better of the two failures.

What it will not do

Not in this version. Wisper Note needs a connection to transcribe.

Every capability is on this page, and every one of them says whether it has shipped or is still in development. The list and those labels are generated from the build’s own configuration rather than written by hand, so a section cannot claim to be finished before the build is, and none of them carries a date, a waiting list or a sign-up.
