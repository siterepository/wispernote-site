Two permissions, and what each one is for.

Wisper Note asks for exactly two things. Here is what macOS will show you, in the order it shows it, and what happens if you say no.

  1. macOS will ask for your microphone.

    Wisper Note records your voice while you hold the dictation key, and sends it to be transcribed. It records nothing when the key is up.

    If you say no: Nothing works, and the app will show you how to turn it back on.

  2. Then it will ask you to allow Accessibility access.

    Accessibility is the only way macOS lets one app type into another. It is how your text reaches your cursor. macOS will warn you that apps with this access can see a lot — that warning is real and you should take it seriously with every app you grant it to.

    What Wisper Note uses it for: typing your text into the app you are in, and reading the text you have selected when you use command mode. Nothing else. It does not read your screen and it does not log your keystrokes.

    If you say no: Wisper Note still works. It copies each result to your clipboard and tells you to press ⌘V. You can turn Accessibility on later in Settings.

On the other platforms

These two are written now so they are ready before those clients are. Neither the Windows build nor the Chrome extension is published yet.

  • Windows may show “Windows protected your PC”.

    That panel appears for any app it has not seen many times yet. Choose More info, then Run anyway. The checksum above is how you confirm you have the file we published.

    If you say no: Nothing installs. The checksum on this page is how you check the file before you run it.

  • Chrome shows the extension’s permissions before you install it.

    Chrome lists everything an extension can do on the install panel, and that list, not this page, is the one to read. Wisper Note has to run on the page you are typing into, so the list will not be short.

    Your microphone is separate and is not part of that list. Chrome asks for it the first time you dictate, on the page you are on, so you are granting it in the moment you can see what it is for.

    If you say no: the extension cannot hear you. Nothing else about your browser changes, and you can grant it later from the extension’s own panel.

One rule about our own screens: the button that takes you to each of these dialogs is labelled Continue, never “Allow”. Only macOS can grant a permission, and a button of ours wearing the system’s word for it would be the confusing case Apple names in its own guidance.

What happens next

  1. 1

    Open the file you just downloaded.

    Drag Wisper Note to Applications and open it.

  2. 2

    Say yes to two things.

    The microphone, then Accessibility. Both explained above.

  3. 3

    Hold ⌥ Space and say anything.

    The app opens a scratch field for exactly this. That first insert is the whole setup.
